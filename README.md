## Interactive Quiz App

**→ [Launch MCAT Biochemistry Quiz](https://collingeorge.github.io/MCAT/)**

A standalone, offline-capable MCAT-style multiple choice quiz built from the complete MileDown Biochemistry flashcard deck. No login. No API key. Works offline.

### Source Material — 437 Flashcards Across 5 Files

| File | Cards | Content |
|------|-------|---------|
| Biochemistry_00 | ~107 | Amino acids (all 20), Proteins, Enzymes (kinetics, regulation, inhibition), Biosignaling |
| Biochemistry_01 | ~89 | Carbohydrates, Lipids, DNA/RNA structure, Replication, Repair, Chromosomes |
| Biochemistry_02 | ~78 | Translation machinery, Gene regulation (operons, lac operon, enhancers), Cell membrane transport |
| Biochemistry_03 | ~88 | Glycolysis enzyme-by-enzyme, Gluconeogenesis, TCA cycle step-by-step, ETC complexes, Fatty acid synthesis, Beta-oxidation, PPP, Urea cycle |
| Biochemistry_04 | ~75 | Glycolysis regulation, Glycogen metabolism, Lipid metabolism (lipoproteins, ketogenesis, DKA), Lab techniques |

All 437 cards converted to MCAT-style 4-option MCQs with explanations.

### Stats Dashboard — 5 panels after every session

1. **MCAT Scaled Score Card** — Estimated 118–132 score mapped from raw % using AAMC B/B section distribution, with percentile ranking, visual score bar, and correct/incorrect counts
2. **Cumulative Performance** — Running MCAT estimate across all sessions, total questions answered, overall accuracy (persists via localStorage)
3. **Subject Breakdown** — Every subject with accuracy bar and STRONG / FAIR / WEAK badge
4. **Strengths & Improvement Areas** — Top 5 strong subjects (≥80%, ≥3 questions seen), top 5 weak subjects (<70%, ranked worst first)
5. **Missed Questions** — Subject label, correct answer, and your answer for every miss

**DRILL WEAK AREAS** — One-click mode that auto-filters the next session to your lowest-scoring subjects only

**RESET STATS** — Clears all cumulative data from localStorage

## Study Notes

This repository also contains a full set of clinically oriented MCAT study notes, organized by discipline and optimized for rapid retention, pattern recognition, and application under exam pressure.

Unlike traditional MCAT materials, this system reframes foundational science in the language of physiology, pharmacology, critical care medicine, molecular mechanisms, and real-world clinical reasoning.

### Repository Structure
```
MCAT/
├── biochemistry/          # Clinical Biochemistry Guide + subsections
├── biology/               # Cellular physiology + clinically relevant mechanisms
├── chemistry-physics/     # OR physics, fluids, gas laws, imaging, kinetics
├── psychology-sociology/  # Behavioral science in clinical scenarios
├── cars/                  # Pattern-based CARS reasoning framework
└── practice/              # MCAT → ICU/OR scenario conversions
```
