# MCAT Biochemistry Quiz

**Live site → https://collingeorge.github.io/MCAT/**

A standalone, offline-capable MCAT-style multiple choice quiz built from the complete MileDown Biochemistry flashcard deck.

## Features
- 123 MCAT-style MCQs across 18 Biochemistry subjects
- Estimated MCAT scaled score (118–132) after each session
- Percentile ranking and cumulative tracking across sessions
- Subject-level strength/weakness analysis
- Drill Weak Areas mode
- Zero dependencies · No login · Works offline
